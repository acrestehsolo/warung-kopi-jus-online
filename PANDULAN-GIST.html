Panduan GitHub Gist

Cara paling mudah — tidak ada build, tidak ada server, jalan di GitHub Pages

⭐
Kenapa GitHub Gist?
  • Tidak ada build — tidak ada "build failed" error
  • Tidak ada server — tidak perlu Deno Deploy, Railway, dll
  • Gratis — 100% pakai GitHub yang sudah kamu pakai
  • Jalan di GitHub Pages — tidak perlu deploy ke tempat lain
  • Order sync — customer order → admin lihat, dari device berbeda
✅ Total waktu: 10 menit (3 langkah mudah)
1
Buat Gist di GitHub
Buka: https://gist.github.com
Klik: tombol "Create new gist" (hijau, di tengah)
Isi form:
  • Description: Warung Kopi Orders
  • Filename: data.json (tekan Enter setelah ketik)
  • Content: {} (kurung kubik kosong)
Klik: tombol "Create public gist" (hijau)
Salin GIST_ID: dari URL di address bar
URL akan seperti: https://gist.github.com/acrestehsolo/abc123def456...
GIST_ID = abc123def456... (bagian setelah nama user)
✅ Gist dibuat! Salin GIST_ID untuk Step 3.
2
Buat GitHub Token

Token izinkan aplikasi kamu menulis data ke Gist.

Buka: https://github.com/settings/tokens
Klik: tombol "Generate new token" → "New token (classic)"
Isi form:
  • Note: Warung Kopi Gist
  • Expiration: No expiration
  • Scopes: centang hanya ☑ gist (yang lain jangan)
Klik: tombol "Generate token" (hijau di bawah)
Salin GIST_TOKEN: muncul satu kali, seperti ghp_xxxxxxxxxxxxxxxxxxxx
⚠️ Jangan lupa — ini hanya ditampilkan sekali!
✅ Token dibuat! Salin GIST_TOKEN untuk Step 3.
3
Pasang ke store.js & Push
Cara: GitHub → repo → klik js/store.js → edit (icon pensil)

Cari baris ini (dekat awal file):

// >>> GANTI DENGAN DATA KAMU <<<
const GIST_ID = "YOUR_GIST_ID";
const GIST_TOKEN = "YOUR_GIST_TOKEN";

Ganti menjadi:

const GIST_ID = "abc123def456...";        // dari Step 1
const GIST_TOKEN = "ghp_xxxxxxxxxxx...";     // dari Step 2
Klik: Commit changes → Push
✅ Selesai! Order dari customer sekarang sync ke admin.
